# 能力短板诊断

六份有效答卷覆盖两个合成案例族：银行流水核对三题、月结工作簿三题。主体全称漏写“（虚构）”在两份月结答卷中出现。T049 来自网页版，T050 来自独立托管 Codex 会话，T053 的相同字段填写完整。这支持“同案例条件下复现”的判断。跨独立主体、跨案例的稳定性仍待检验。

T053 自动分为 65.7143/80；其中数值和状态均获满分。答卷将连续区域写入仅接受单格的引用字段，且其公式超出了评分器的函数覆盖范围。用独立表格引擎逐项重算后，五组输入的结果全部符合预期。因此，证据格式、公式兼容性、业务判断应分别记录。

## 阅读顺序

1. 在[诊断表](诊断表.csv)按归因筛选已确认的偏差、待裁定的字段、评分器问题及已观察到的正确处理。每行给出题项、分母、业务影响和反例。
2. 通过[证据索引](证据索引.csv)找到题号，再打开[结构化证据摘录](evidence.json)。其中保留关键答卷字段、实际分数及 T050、T053 的逐场景复算值。核验方可用 SHA-256 比对所持原始 JSON 文件。
3. [复测计划](复测计划.md)列出下一轮拟加入的对照样本、判断标准和结论升级条件。

## 如何解释样本

按“适用且能判定的题数”作分母，同一题内多个单元格或重算情景保留在该题之内。六份答卷都要求精确的主体字段，因此全体可观察到 2/6 次省略；三份月结答卷中为 2/3，两个业务案例族中只在其中一个族出现。此处记录的是开发样本观测值，不能据以估计产品总体发生率。网页与托管样本在本次没有按同题同轮配对，不能据分差比较两种运行方式的优劣。

本目录含已作答开发题的信息。用于评测时，应由评分端保存。新一轮独立作答只向受测端提供对应的单题材料。
