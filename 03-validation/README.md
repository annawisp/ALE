## 填写顺序

1. **A 独立验题**。只看该题任务和原始材料。填题项 ID、输入事实、对应对象、重算结果、状态、两侧来源位置和理由。保存一份带时间的初稿。
2. **B 答案比对**。打开参考答案，将初稿与参考结果并排记录。出现差异时写明哪条规则或哪笔业务导致分歧，给出本题可试评、需补材料或待裁定的意见。
3. **C 答卷评分**。取得实际答卷后，登记题号及运行编号。P1–P5 衡量专业论证，E1–E5 衡量证据是否支持结论。每个分项取 0、1 或 2 分，未评项目留空。扣分项要能定位答卷原句和原始材料。两组小计各 10 分，将实评分与自动分、门槛状态一同保存。
4. **D 问题登记**。登记问题编号、题项、事实、影响、处理意见、状态和裁定版本。保留原始答卷与原评分，以便按同一版本复算。

指导书与模板沿用建库时的教学样例。现行规则以[评分说明](../05-scoring/README.md)为准，试评裁定可以从上表逐项查看。
