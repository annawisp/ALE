# 开发集与首轮试评清单

本目录提供 24 道可复跑的合成财务业务题。原设计按案例分组，12 个案例各有 6 道变体。本次公开其中 4 个开发案例；其余 8 个案例的 48 道题保留为候选盲测集。公开开发题适合校准评分、演练收卷和回归测试。

| 开发案例 | 题号 | 业务任务 | 首轮试评 |
|---|---|---|---|
| F01 | T001–T006 | 逐笔银行核对 | T001、T002、T005 |
| F03 | T013–T018 | 分次收款核销 | T013、T014、T017 |
| F07 | T037–T042 | 核对票据、形成分录草稿 | T037、T038、T041 |
| F09 | T049–T054 | 月结工作簿与公式检查 | T049、T050、T053 |

每个案例覆盖六类变化，包括常规任务、真实异常、易误报反例、期间或金额边界、缺失或歧义、格式或控制扰动。主体及数据均为虚构。按题目给定的规则判断业务事实。

| 文件 | 用途 |
|---|---|
| [development_inputs_v1.0.zip](development_inputs_v1.0.zip) | 受测端资料。按“受测包／案例／题号”组织，含任务书、原始材料、回答模板、字段说明及本题文件校验值。 |
| [开发集划分.csv](开发集划分.csv) | 逐题列出能力、维度、输入目录和首轮试评标志。 |
| [首轮12题试评清单.csv](首轮12题试评清单.csv) | 出题时的抽题清单。“人工复核”列保留建库时的初始值。各次运行和评分以对应运行记录为准。 |

## 投一题

在仓库根目录解压输入。以下命令使用 Python 3.10 或更高版本，Windows 上也可用 `py -3` 代替 `python`。

```bash
python -m zipfile -e 02-dataset/development_inputs_v1.0.zip local-run/input
```

以 T005 为例，向受测端提交 `local-run/input/受测包/案例01/T005/` 下全部文件，含子目录。每题使用独立会话，同时保留原始输入和首次返回的文件。按题号将答卷归档为 `local-run/results/T005/response.json` 和 `workpaper.md`。月结题另收 `corrected.xlsx`。专家答案和评分程序留在评分端。评分步骤见 [05-scoring](../05-scoring/README.md)。
