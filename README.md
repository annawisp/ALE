# Chatgpt for accounting测评

用合成账务材料测试 Accounting 在什么条件下会漏报、误报、错误匹配、遗漏范围字段或给出不可复核的证据。仓库同时保存题目、评分依据、真实交付物与复核结论，方便第三方拿同一份答卷重新算分。

**第一次看项目**，从[工作 SOP](SOP.md)开始。想核对某个结论，可先看[首轮 12 题试评结果](06-results/README.md)，再按题号查[诊断表与证据](07-diagnosis/README.md)。

## 从现有答卷重现结果

下载并解压仓库，进入仓库根目录，用 Python 3.10 或以上执行以下命令。Windows 可将 `python` 换为 `py -3`。

```bash
python 05-scoring/verify_release.py
python 06-results/replay.py
```

第一条校验公开开发题的参考答案与评分边界。第二条从首轮 12 份真实答卷重新计算现行客观分，并核对历史分、分项和文件指纹。两条命令都可离线执行。新发起模型作答的运行条件见[独立作答说明](04-execution/)。

[归档对照表](归档对照表.md)列出原交付物、公开位置与保留范围。候选盲测题保留在评审侧，避免在正式运行前暴露具体材料和标准答案。
