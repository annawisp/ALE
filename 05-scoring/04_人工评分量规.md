# 人工评分量规 v1.0（待双评校准与正式冻结）

本表用于补足自动检查不能判断的20分。评审只评价实际交付；不能把参考答案中的解释当作受测系统已经写出。先逐项记录0、1或2分，再求和填入manual_review.json。未复核项保持null，不按满分处理。

统一锚点：2分=该标准的全部适用事项满足；1分=有明确可定位的遗漏，但未改变业务结论；0分=缺失、核心理由错误，或遗漏足以改变结论。每个低于2分的项目记录题项ID、输出原文位置和扣分理由。无需相关补证的正常题，明确说明无需待核即可满足对应标准。

| 类别 | 编号 | 2分判据 |
|---|---|---|
| 专业论证 | P1 | 使用题定主体、期间和业务规则，并解释为何适用于相关事项 |
| 专业论证 | P2 | 关键金额、分配、差额或公式处理有可复算的过程，符号和口径一致 |
| 专业论证 | P3 | 解释覆盖所有需作结论的事项；已完成与待核部分分别说明 |
| 专业论证 | P4 | 缺失、歧义、矛盾或例外的处理与材料一致；正常事项未被凭空扩大为问题 |
| 专业论证 | P5 | 对待核事项提出具体资料需求/复核动作；无需后续动作时明确说明；不越权给出整体审计意见 |
| 证据语义 | E1 | 引用的主体、账户、期间和交易身份确实对应所述结论 |
| 证据语义 | E2 | 引用内容直接支持关键金额、匹配关系或事实；仅有文件名不视为支持 |
| 证据语义 | E3 | 保留材料中的限定、缺失及否定表述，不把“未取得”改写成“已证实” |
| 证据语义 | E4 | 已提供的相反证据、版本冲突与异常均得到解释；没有相反证据时不虚构冲突 |
| 证据语义 | E5 | 每项结论与依据有清楚对应；不存在以少数已核实事项替代全部事项的推断 |

professional_reasoning=P1至P5之和；evidence_semantics=E1至E5之和。需填写实际复核人、复核日期；不得把程序模拟评分作为人工签核。

两位评审先独立评分，再记录每个标准是否一致及差值。对分歧先定位输入、规则或量规问题；修题、补允许解或修量规后升版本并重评受影响题。不要仅平均两个争议分数。

业务判断合理但公式表达超出当前自动评分器支持范围时，标记“评分器不支持，待人工裁定”；保留原始答卷、重算证据及裁定理由，在修正评分器并重跑前，不把自动检查失败直接计为插件业务错误。

## 2026-11-20 试评裁定（评分口径 v1.1）

1. 主体范围按 response.json 的 scope.entity 与任务书全称逐字核对，包含“（虚构）”。底稿使用全称不能替代 JSON 中缺失的标记。沿用原范围扣分与通过门槛。
2. 对月结差异率，接受直接列明证据，也接受沿本题同一工作簿、同一份答卷的公式链追溯。以 T049 为例，B6 引用自身、实际费用 B2 和预算 B5，B2 项列示本单元格及明细 C2 至 C7。核实公式与引用、上游结果及状态后，B6 可继承实际已列明的底层证据。仅引用汇总表、仅写文件名、上游存在无效引用，或依赖链断裂，均不自动补足分数。
3. 现有自动识别适用于月结 B6 → 月结 B2 → 明细的已知公式结构（T049 至 T054）。其他等价公式、有条件分支或其他业务题有相同主张时，逐项核验实际依赖与材料，留存裁定。题项数值、状态、范围及其他维度仍各自计分；人工评分仍须按 P1–P5、E1–E5 完成。
