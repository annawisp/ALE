# 开发题评分与复算

**现行客观评分基线为技术版 v1.2，正式盲测评分规则待冻结。** 本目录用于给 24 道公开开发题评分。专家答案由项目按题定业务规则拟制，并与锁定的合成材料核对。每道题包含参考答卷、关键项、证据引用和逐项解释。独立专家签核情况应查相应的人工复核记录。

| 文件 | 用途 |
|---|---|
| [development_reference_v1.1.zip](development_reference_v1.1.zip) | 专家参考资料版本为 v1.1，评分程序技术版本单独管理。按“答案包／专家答案／题号”组织的 24 份参考资料。6 道月结题含参考工作簿，其余题按其交付要求提供参考答案。 |
| [score.py](score.py) | 公开开发题的统一离线评分入口，依赖 Python 3.10 或更新版本的标准库。支持公开月结工作簿。 |
| [04_人工评分量规.md](04_人工评分量规.md) | 专业论证 P1–P5、证据语义 E1–E5 的评分锚点及 v1.1 两项裁定。 |
| [verify_release.py](verify_release.py) | 自检题号白名单、首轮清单、输入字节校验值、参考答卷分数及几个容易误判的情景。运行期间仅使用临时目录。 |

## 给实际答卷评分

在仓库根目录运行下列命令。按[受测包说明](../02-dataset/README.md)先解压输入并放好实际答卷，然后解压评审端资料。

```bash
python -m zipfile -e 05-scoring/development_reference_v1.1.zip local-run/gold
python 05-scoring/score.py --test-root local-run/input/受测包 --gold-root local-run/gold/答案包 --results local-run/results --task T005 --output local-run/results/T005/自动评分.json
```

| 自动分构成 | 分数 | 核对事项 |
|---|---:|---|
| 范围 | 10 | 题号，以及主体全称、账户、期间、币种等题定字段 |
| 题项结果 | 30 | 金额、分配、匹配集合等结构化结果 |
| 处理状态 | 10 | 已匹配、待核等判断与题设一致 |
| 证据位置 | 10 | 引用可定位，涵盖要求的来源；月结差异率可沿符合条件的汇总证据链核对 |
| 交付 | 10 | 答卷、工作底稿及适用的修正工作簿 |
| 完整性 | 10 | 原始材料完整，题项编号及题号符合要求 |

运行报告分别列出自动分、范围等门槛问题、关键项和致命错误。人工两类各 10 分。完成复核后，可复制该题的 `manual_review_template.json` 至实际答卷目录，保存为 `manual_review.json`，填入实际得分、复核人及日期，再运行同一条命令。现有试评程序在总分达到 85 分且相关门槛均满足时返回“通过”。正式盲测的人工评分与通过线仍待校准冻结。仅有自动分时，最终分保留空值。

v1.2 使用受限解释器重新计算月结公式，支持 SUM、IF、ROUND、引用型 COUNT 和 ROWS 及基本运算。COUNT 按真实数值计数，ROWS 按引用矩形的物理行数计数。程序变更明细及预算，比较合计、小计、差异率等目标公式在 13 组输入下的输出。逐格证据、主体全称和其他门槛延续原口径。出现超出支持范围的公式，报告列出待核公式，客观分暂计，最终分留空。评审保留原答卷并以独立引擎复算。

## 重现发布自检

```bash
python 05-scoring/verify_release.py
```

已核验 144 个输入文件、126 个参考资料文件，以及 12 道首轮试评题的归属。24 份公开参考答卷全部获得 80/80 自动分。另用参考答卷的临时副本验证三条判据：强行匹配歧义交易会触发致命错误；省略主体标记仍扣分，同时可认可完整的月结追溯链；断开的追溯链不能获得满分。此命令还验证 T005-r1 的五种评分情形，以及 T053 的真实交付、13 组独立预期（四个目标共 52 格）、4 项函数语义检查及 11 个对照。另可从仓库根目录运行 `python 06-results/replay.py`，从原始答卷回放首轮成绩。

评审端另用覆盖所有题型的私有 v1.2 评分器重算 72 题、345 个题项，72 份参考答卷均获 80/80。588 组正反例检查和另 18 个模板工作簿对照全部通过。这里统计评分系统的技术检查；首轮插件实答共 12 份。私有逐题材料与报告由评审端保管。

## T005 单题修订的配套评分

给 T005-r1 的新答卷评分时，将 [T005-r1 单题评分资料 v1.2](T005-r1_单题评分包_v1.2.zip) 和[配套单题受测包](../02-dataset/T005-r1_单题受测包.zip)解压至仓库根目录下的 `t005-r1/`。把新答卷放入 `t005-r1/结果/T005/`，然后从仓库根目录运行统一评分程序。

```bash
python 05-scoring/score.py --test-root "t005-r1/受测包" --gold-root "t005-r1/答案包" --results "t005-r1/结果" --task T005 --output "t005-r1/结果/T005/自动评分.json"
```

单题受测端与评分端清单对应 T005-r1 修订题面。首轮 T005 继续按开发集 v1.0 受测材料、配套专家资料及字段裁定解读。[T005 修订验证](../03-validation/T005-r1_修订与验证.md)
