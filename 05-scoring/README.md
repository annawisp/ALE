# 开发题评分与复算

本目录用于给 24 道公开开发题评分。专家答案由项目按题定业务规则拟制，并与锁定的合成材料核对。每道题包含参考答卷、关键项、证据引用和逐项解释。独立专家签核情况应查相应的人工复核记录。

| 文件 | 用途 |
|---|---|
| [development_reference_v1.1.zip](development_reference_v1.1.zip) | 按“答案包／专家答案／题号”组织的 24 份参考资料。6 道月结题含参考工作簿，其余题按其交付要求提供参考答案。 |
| [score.py](score.py) | 离线自动评分器。保留 v1.1 对公开题的判定与命令接口，移除了仅供非公开工作簿使用的模板分支。依赖 Python 标准库。 |
| [04_人工评分量规.md](04_人工评分量规.md) | 专业论证 P1–P5、证据语义 E1–E5 的评分锚点及 v1.1 两项裁定。 |
| [verify_release.py](verify_release.py) | 自检题号白名单、首轮清单、输入字节校验值、参考答卷分数及几个容易误判的情景。运行期间仅使用临时目录。 |

## 给实际答卷评分

在仓库根目录运行下列命令。按[受测包说明](../02-dataset/README.md)先解压输入并放好实际答卷，然后解压评审端资料。

```bash
python -m zipfile -e 05-scoring/development_reference_v1.1.zip local-run/gold
python 05-scoring/score.py --test-root local-run/input/受测包 --gold-root local-run/gold/答案包 --results local-run/results --task T005 --output local-run/results/T005/自动评分.json
```

| 自动分构成 | 分数 | 核对事项 |
|---|---:|---|
| 范围 | 10 | 题号，以及主体全称、账户、期间、币种等题定字段 |
| 题项结果 | 30 | 金额、分配、匹配集合等结构化结果 |
| 处理状态 | 10 | 已匹配、待核等判断与题设一致 |
| 证据位置 | 10 | 引用可定位，涵盖要求的来源；月结差异率可沿符合条件的汇总证据链核对 |
| 交付 | 10 | 答卷、工作底稿及适用的修正工作簿 |
| 完整性 | 10 | 原始材料完整，题项编号及题号符合要求 |

运行报告分别列出自动分、范围等门槛问题、关键项和致命错误。人工两类各 10 分。完成复核后，可复制该题的 `manual_review_template.json` 至实际答卷目录，保存为 `manual_review.json`，填入实际得分、复核人及日期，再运行同一条命令。现行规则总分达到 85 分，且满足范围、规定事实、关键项、证据、交付等门槛时可判通过。仅有自动分时，最终分保留空值。

现有工作簿解释器支持 SUM、IF、ROUND 和基本运算。报告遇到无法解释的等价公式时，保留原答卷，使用独立表格引擎变更输入复算，将两份结果交给复核人裁定。

## 重现发布自检

```bash
python 05-scoring/verify_release.py
```

已核验 144 个输入文件、126 个参考资料文件，以及 12 道首轮试评题的归属。24 份公开参考答卷全部获得 80/80 自动分。另用参考答卷的临时副本验证三条判据：强行匹配歧义交易会触发致命错误；省略主体标记仍扣分，同时可认可完整的月结追溯链；断开的追溯链不能获得满分。此自检反映参考资料与评分程序能否配套运行，插件表现须以真实答卷为依据。
