# 能力地图与题库设计

[第二轮 AI 行业财务 BP 评测蓝图](round-02-ai-finance-bp.md)列出六项可验收能力、R2-12 单题预检和 24 道候选题。

[下载原始设计工作簿](ALE_能力地图与评测设计_v1.0.xlsx)。首张表按能力 ID 记录业务领域、可验收动作、候选输入、预期交付与评分方法。另外五张表分别记录初版蓝图、评分规则、样本字段、评分示例及范围与依据。

先选一项能观察到的动作。例如，从“银行核对”中选“存在两个合理候选时暂停匹配”，在题面指定能用的证据，在输出模板留出状态、候选及差额字段，再为金额冲突、证据缺失等情况各造一题。出题人应在投题前约定哪些字段必须精确相等，哪些允许等价证据，哪些需要人工复核。

初版蓝图列出 60 个设计位置，后续实际制作以 12 个案例、72 道题为准。能力地图中的能力 ID 和题库案例编号属于不同列，例如能力 ID F01 表示按模板编制月度报告，案例编号 F01 表示逐笔银行核对。查题时同时记录能力 ID、案例编号与题号。[开发题对应关系](../02-dataset/开发集划分.csv)
