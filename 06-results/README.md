## 离线复现

在仓库根目录运行以下命令，只需 Python 标准库。

```bash
python3 06-results/replay.py
```

程序核对 27 份提交文件和补充六题的输入指纹，再用现行评分器重跑全部 12 份原答卷。它检查两版分项、保留的扣分与门槛、28 项对照、T053 已归档的五组复算结果及成绩表。T002 的人工分从匿名签核记录复用。输出每行依次为历史客观分、同卷调整和当前客观分。

复现旧机器输出可从 Git 历史取出 SHA-256 为 `418ecc8fcd48fbe51d2698596868654ddb536d2f899249359f46fbe44c965cb4` 的 v1.1 `score.py`。将它另存为 `score_v1_1.py` 后运行 `python3 06-results/replay.py --historical-scorer score_v1_1.py`，可对照全部 12 份历史完整报告。在 `06-results` 目录运行 `sha256sum -c SHA256SUMS.txt` 可检查发布文件的完整性。
