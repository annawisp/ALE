| 文件 | 目录或字段 | 用途 |
|---|---|---|
| [历史六题证据](pilot_evidence.zip) | `submissions/<题号>/`、`records.json` | T001、T002、T005、T049、T050、T053 共 15 个答卷文件及其指纹。每题有 JSON 和工作底稿，三道月结题各另有 Excel。 |

## 在本地验证

在仓库根目录执行。只需 Python 标准库。

```bash
python3 06-results/replay.py
```

程序核对 27 份交付原件的 SHA-256、补跑六题的全部输入指纹，在临时目录用公开 v1.1 评分器逐题重算，逐字段检查 12 份完整报告，再将 28 行对照分别与原答卷和专家答案核对，并核查首轮成绩表。T002 的人工 20 分来自已完成的匿名历史记录。回放仅计算已记录指标的合计及评分门槛，不重新评价人工判断。可另外在本目录运行 `sha256sum -c SHA256SUMS.txt` 检查发布文件。

三道网页试评在选用 Accounting 的 ChatGPT 对话内完成。九道托管试评分别在独立 Codex 子会话中加载官方 Accounting 指令，由受限文件进程处理题目材料。各渠道均未留存具体模型快照。仓库另附用于新一轮试评的[本地 Docker 工具](../04-execution/README.md)。当前 12 份答卷来自上述两种历史渠道，均为公开开发样例；结论限于已观察的任务和运行入口。
